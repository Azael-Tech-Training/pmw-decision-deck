# Established Prior Knowledge and Goals

The user starts with an intermediate electronics background, understanding voltage, current, Ohm's law, and basic transistor operations (like switching). However, they lack experience applying these principles to automotive systems (e.g., vehicle wiring, ECU architecture, high-power actuator control).

## Evidence
- The user self-reported their background in the initial workspace survey.
- They selected the intermediate profile and expressed an interest in both diagnostic and design-focused outcomes.

## Implications
- We can skip basic electricity concepts (what is voltage, what is current, what is a resistor) and dive straight into how transistors are used as high-frequency switches to modulate average power.
- Future lessons will use standard transistor diagrams (BJTs/MOSFETs) as intuitive stepping stones to describe PWM output stages in automotive ECUs.
