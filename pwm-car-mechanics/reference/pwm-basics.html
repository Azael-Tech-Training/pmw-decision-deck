Short Circuits & Fuse Physics

  • Ohm's Law in Faults: $I = V / R$. When a power wire shorts to the chassis ground before the load, resistance drops to near-zero ($R \approx 0.05\ \Omega$), causing current to surge instantly.
  • Joule Heating: $P = I^2 \times R_{\text{fuse}}$. Heating rate spikes exponentially with current. A normal 6A load generates only 0.7W of heat in a fuse, whereas a 240A short-circuit current generates over 1,150W, melting the fuse link in milliseconds.
  • Low-Side Control Short: A short-to-ground after the load bypasses the switch, but the load remains in series. Current is limited by the load's resistance. The fuse does not blow, but the load runs continuously.
  • High-Side Control Short: A short-to-ground before the load bypasses the load entirely. When the switch closes, current flows directly from battery to chassis ground. The fuse blows immediately to prevent fire.

Common Automotive PWM Frequencies

Component Typical Frequency Switching Strategy
Cabin Blower Fan 100 Hz – 500 Hz Low-Side PWM (duty cycle varies speed)
Radiator Cooling Fan 100 Hz – 300 Hz Low-Side or High-Side PWM (high current driver)
Electronic Fuel Pump 100 Hz – 20 kHz Fuel pump driver module (FPDM) regulated speed
EVAP Purge Solenoid 10 Hz – 30 Hz Slow switching to regulate gasoline vapor flow
Electronic Throttle Body 1 kHz – 5 kHz Dual-direction H-bridge for precise motor positioning
Fuel Injectors Dynamic (with Engine RPM) Pulse width dictates fuel volume directly

Diagnostic Measurement Checklist

Using a Digital Multimeter (DMM)

  • DC Voltage Mode: Measures $V_{avg}$. Excellent for quick sanity checks. If a 12V supply reads 6V on a fan, the duty cycle is likely around 50%.
  • Duty Cycle (%) Mode: Select DMM to Hz/% mode. Connect the black probe to a known good ground, and back-pin the signal line with the red probe. Select % to read command value.
  • Frequency (Hz) Mode: Verifies signal stability. A reading of 0 Hz or erratic shifting suggests a lost control wire or bad driver.

Using an Oscilloscope (PicoScope/etc.)

  • Channel Setup: Set to DC coupling. For 12V systems, set the vertical voltage scale to ±20V or 0–20V. For 5V sensors, set to 0–10V.
  • Timebase Setup: For a 100 Hz signal, one cycle is 10ms. A timebase of 5ms/div or 10ms/div allows you to view 5–10 complete pulses.
  • Trigger: Select standard "Auto" or "Repeat" trigger. Set the trigger threshold (voltage level) to roughly half the signal's peak height (e.g., 6V for a 12V signal) on a "Rising Edge."
